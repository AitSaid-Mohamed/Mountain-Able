# Screenshots

UI captures of the running Mountain-Able frontend (React + Vite) against the
seeded backend. Desktop shots are 1440×900 at 2× device scale; mobile shots are
375×812 at 2×. Full-page where the page is taller than the viewport.

| File | What it shows |
|------|---------------|
| `01-home.png` | Full home page (logged out): hero, Most Popular villages, About band, and FAQ accordion. |
| `02-villages-listing.png` | Villages listing with the search/filter bar, the 2-column village card grid, and the sticky Leaflet map of Italy. |
| `03-villages-filtered.png` | Listing filtered by Region = Abruzzo and Minimum rating = 4+ stars, showing the 3 matching villages and the map. |
| `04-village-details.png` | Full village detail page (Scanno): gallery, description, sidebar (map, location, municipality, stats, attractions, events). |
| `05-village-reviews.png` | The reviews section (cropped), logged in as a tourist: average score, rating distribution, the write-review form, and the review list. |
| `06-login-modal.png` | The login modal open over the (blurred) home page, with email/password fields, remember-me, and the disabled "Login with Google" future feature. |
| `07-signup.png` | The sign-up page: labelled two-column field grid, required-field markers, avatar upload, and password-strength hint. |
| `08-mobile-home.png` | Home page on a 375×812 mobile viewport: collapsed hamburger nav and stacked hero/cards. |
| `09-mobile-listing.png` | Villages listing on mobile with the map panel revealed via the "Hide/Show map" toggle, single-column cards, and pagination. |
